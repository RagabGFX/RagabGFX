GITHUB-READY PORTFOLIO
=======================

This version keeps the website design and visuals, but optimizes the large image assets
for web hosting.

UPLOAD:
1. Upload the CONTENTS of this folder to your GitHub repository (not the ZIP itself).
2. Make sure index.html is in the repository root.
3. In GitHub: Settings > Pages > Deploy from branch > main / root.
4. Open the generated GitHub Pages URL.

IMPORTANT:
- Do not upload the ZIP as the website.
- Upload the files/folders inside it.
