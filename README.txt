RagabGFX — new homepage (v15) — UPDATE OVERLAY for the existing site
=============================================

EN:
This is an UPDATE OVERLAY, not a complete website: it works on top of
your existing files. Upload the CONTENTS of this folder into your
existing RagabGFX repo (the same folder that already has category.html,
style.css, script.js and your assets/ folders). Do NOT delete anything
already there — the gallery pages need those files.

What overwrites existing files:
- index.html replaces your old homepage.
- category.html replaces your old gallery page. It is the same page as
  before with ONE addition: the Identities gallery is now filled with
  your campaign work. Matchdays, Hero Graphics and Manipulation
  galleries are unchanged.

What is new (nothing else of yours changes):
- rgx15.css and rgx15.js serve the new homepage only.
- assets/rgx15/ holds the new homepage images.
- assets/identities/ holds the Identities gallery images.
- assets/fonts/ holds the two fonts.

The new homepage links to all four galleries (Matchdays, Hero
Graphics, Manipulation, Identities) with relative links.

If you use GitHub: drag everything in, commit, and GitHub Pages updates
by itself in a minute or two.
